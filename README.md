# culture-diachronic-embeddings

Код к статье **«Когда слово становится понятием? Диахронические векторные модели в исследовании культуры (на материале британской прессы XIX века)»**.

## Содержание

- `analysis.ipynb` — ноутбук для Google Colab, воспроизводящий расчёты и визуализации, использованные в статье.

## Запуск

Откройте `analysis.ipynb` в Google Colab и выполните все ячейки по порядку.

Ноутбук автоматически загружает опубликованные десятилетние векторные модели проекта *Living with Machines* с Zenodo. Общий объём загрузки составляет около 1,5 ГБ.

## Данные

Используются опубликованные модели *Living with Machines*:

Zenodo record **7181682**.

Методическое описание моделей:

Pedrazzini N., McGillivray B. *Machines in the Media: Semantic Change in the Lexicon of Mechanization in 19th-Century British Newspapers*. NLP4DH, 2022. DOI: 10.18653/v1/2022.nlp4dh-1.12.

Репозиторий не содержит файлов моделей и производных данных.
